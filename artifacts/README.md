# artifacts/

Source files for rendered artifacts (App Store gallery, design mockups, etc.),
kept in the repo so they're version-controlled and editable — not stranded in a
scratch dir. Each is a self-contained HTML page published to claude.ai.

- `app-store-gallery.html` — App Store screenshot gallery + listing copy,
  designed to appeal to art-school students.
  Live: https://claude.ai/code/artifact/2d27f37d-383e-4843-bc1d-95a576db10d2

To edit one: change the file here, then re-publish it (same path keeps the URL).
